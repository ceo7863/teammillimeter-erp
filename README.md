# TeamMillimeter ERP Cursor 프로젝트

이 ZIP은 Cursor에서 바로 열 수 있는 React + TypeScript + Vite 프로젝트 폴더입니다.

## 사용 방법

1. ZIP 압축을 풉니다.
2. Cursor에서 `teammillimeter-erp` 폴더를 엽니다.
3. Cursor 터미널에서 실행합니다.

```bash
npm install
npm run dev
```

## 중요한 안내

ChatGPT 캔버스의 최신 ERP 전체 코드를 이 환경에서 직접 파일로 추출하는 기능은 없어,
이 ZIP에는 다음이 들어 있습니다.

- React/Vite 실행 환경
- shadcn 대체용 Card/Button 컴포넌트
- lucide-react, jspdf 의존성 설정
- 이전에 생성된 `Teammillimeter_Web_Erp_Mvp_snapshot.tsx` 백업 파일
- 최신 코드를 붙여넣을 `src/App.tsx`

최신 ERP 전체 코드는 ChatGPT 캔버스에서 전체 선택 후 `src/App.tsx`에 붙여넣으면 됩니다.
